Section 01Foundations

Why Do We Need NumPy?

The problem

Python lists can hold numbers just fine. Here's a week of Tokyo temperatures, stored the "list" way:

the_list_way.py
tokyo_temps = [18, 19, 21, 20, 22, 23, 21]
# convert every value to Fahrenheit...
fahrenheit = []
for t in tokyo_temps:
    fahrenheit.append(t * 9/5 + 32)

That's a manual loop for one simple conversion, on one city, for one week. Now imagine five cities, 365 days, and needing that same math every single time.

  • Element-wise math needs an explicit loop — Python never does it "in bulk."
  • Lists can silently mix types, so there's no guarantee every value is even a number.
  • Nested lists (a list of lists) are a clumsy stand-in for a real grid — rows and columns.
  • There's no built-in idea of "shape," so bugs like a missing city or an extra day slip through.
  • Pure-Python loops don't scale — at real data sizes, they're dramatically slower than they need to be.
Data Science Insight

NumPy (Numerical Python) gives Python a fast, fixed-type, N-dimensional array, plus vectorized operations — the same math applied to every element at once, without writing the loop yourself.

List vs NumPy array
FeaturePython ListNumPy Array
StructureFlat, unordered containerFixed-shape, same-type grid (N-D)
Data TypesMixed, any type per elementOne dtype for the whole array
Element-wise MathManual loop requiredVectorized — arr * 2 just works
Memory LayoutArray of pointers to objectsContiguous block, fixed-size elements
Speed at ScaleSlows down fastBacked by compiled C loops
Shape AwarenessNone — nested lists onlyNative .shape, .ndim
Where NumPy sits

NumPy is the layer between raw Python and everything built for numerical work on top of it — Pandas included.

Common Mistake

Treating a NumPy array like a Python list that happens to be faster. Arrays are fixed-type and fixed-shape by design — appending to one in a loop, the way you'd grow a list, defeats the whole point and is slower than a list would have been.

Real-World Use Case

Every image is a NumPy array of pixel values, every audio clip a NumPy array of samples, and every Pandas DataFrame is built from NumPy arrays underneath. Learning arrays first is what makes all three make sense.

Creating Arrays

Why do we need this

Arrays come from three places: converting existing Python data, generating a pattern (zeros, ranges, evenly spaced points), or sampling randomly. Every project starts with one of these.

From a Python list

The most direct route — wrap a list (or list of lists) in np.array().

notebook cell
tokyo = [18, 19, 21, 20, 22, 23, 21]
arr = np.array(tokyo)
print(arr, arr.dtype, arr.shape)
Output
[18 19 21 20 22 23 21] int64 (7,)

A list of lists becomes a 2-D array — one row per inner list, as long as every inner list is the same length.

Common Mistake

Passing lists of different lengths into np.array(). Modern NumPy refuses to guess and raises an error — it needs every row to be the same length, unlike a plain Python list of lists.

Basic indexing

    
A 2-D array is indexed [row, col] — one pair of brackets, comma-separated, not two separate brackets like nested lists.

print(temps[1, 2])
# the whole Cairo row
print(temps[1])
# every city's Wednesday temperature
print(temps[:, 2])

Slicing a range

    
Slices work like Python list slices — start:stop, stop excluded — but now along any axis.

    

      
notebook cell

      
# first 3 days, for the first 2 cities
print(temps[0:2, 0:3])

      
Output

      Common Mistake
      
Assuming a slice of an array is a copy, the way it can feel with a list. A NumPy slice is a view — modifying it modifies the original array too. Use .copy() when you actually need an independent version.

Array Operations & Broadcasting


    
Vectorized math

    
Every arithmetic operator applies element-wise, automatically — this is the whole reason NumPy exists.

    

      
notebook cell

      
# Celsius -> Fahrenheit, for every city and day, no loop
fahrenheit = temps * 9/5 + 32
print(fahrenheit[0])  # Tokyo's week, in Fahrenheit

      
Output
[64.4 66.2 69.8 68.  71.6 73.4 69.8]

    


    
Elementwise calculator — interactive

    
Apply an operation to the whole temperature array and watch every value update at once.

    

      

        

          
        

        

      

      

      

    


    

      Data Science Insight
      
Comparison operators (>, ==) are also vectorized — they don't return one True/False, they return a full array of them, which is exactly what feeds boolean masking from Section 3.

    


    
Broadcasting

    
Broadcasting is how NumPy applies an operation between arrays of different shapes — by "stretching" the smaller one, without actually copying data. A 1-D array of 7 day-offsets can be added to every row of the 5×7 grid at once.

    

      
notebook cell

      
correction = np.array([0, 0, 1, 1, 1, 0, -1])  # shape (7,)
adjusted = temps + correction  # temps is (5, 7) -> broadcasts across every row
print(adjusted.shape)

      
Output
(5, 7)

    

    

      
Array AArray BCompatible?Why

      
(5, 7)(7,)YesB stretches across all 5 rows

      
(5, 7)(5, 1)YesB stretches across all 7 columns

      
(5, 7)()YesA single scalar applies everywhere

      
(5, 7)(3,)No7 and 3 don't match, and neither is 1

    


    

      Common Mistake
      
Assuming any two arrays can be combined. NumPy compares shapes from the right, dimension by dimension — each pair of dimensions must be equal, or one of them must be 1. Otherwise it raises a ValueError.

Reshaping, Stacking & Splitting


    
Reshape

    
.reshape() rearranges the same elements into a new shape — the total element count has to stay identical.

    

      
notebook cell

      
flat = temps.flatten()       # 35 elements, 1-D
weeks = flat.reshape(5, 7)  # back to 5x7
print(flat.shape, "->", weeks.shape)

      
Output
(35,) -> (5, 7)

    


    
Reshape playground — interactive

    
The 35 flattened temperature values, reshaped live. Only shapes whose dimensions multiply to 35 will work — exactly like in real NumPy.

    

      

        

        

      

      

      

    


    

      Pro Tip
      
Pass -1 for one dimension and NumPy figures it out: flat.reshape(7, -1) automatically becomes (7, 5), since 35 ÷ 7 = 5.

    


    
Stacking arrays

    
A new city's readings — as a separate 1-D array — can be stacked onto the existing grid with np.vstack().

    

      
notebook cell

      
berlin = np.array([14, 15, 13, 16, 15, 14, 13])
extended = np.vstack([temps, berlin])
print(extended.shape)

      
Output
(6, 7)

    

    

      
FunctionStacks alongShape requirement

      
np.vstack()New rows (axis 0)Same number of columns

      
np.hstack()New columns (axis 1)Same number of rows

      
np.concatenate()Any given axisMatching on every other axis

    


    
Splitting arrays

    
np.split() is the reverse — cut one array into several equal pieces.

    

      
notebook cell

      
# split the week into (Mon-Wed) and (Thu-Sun)
first_half, second_half = np.split(temps, [3], axis=1)
print(first_half.shape, second_half.shape)

      
Output
(5, 3) (5, 4)

    


    

      Common Mistake
      
Calling .reshape() with dimensions that don't multiply to the original element count. 35 elements can become (5,7), (7,5), or (35,) — never (5,6). NumPy raises a ValueError rather than guessing.

Aggregations, Axes & Statistics


    
Aggregating the whole array

    
With no axis specified, an aggregation collapses every element down to one number.

    

      
notebook cell

      
print(temps.mean(), temps.max(), temps.min())

      
Output
19.4 33 2

    


    
The axis argument

    
axis=0 collapses down the rows (one result per column). axis=1 collapses across the columns (one result per row). It's the single most-confused idea in NumPy — the interactive board below makes it concrete.


    

      

        

          
        

        

          
        

      

      

      

    


    

      Data Science Insight
      
A useful trick: axis is the dimension that disappears. temps is (5, 7); temps.mean(axis=1) makes the 7 vanish, leaving one mean per city — shape (5,).

    


    
argmax / argmin

    
These return the position of the extreme value, not the value itself — essential for answering "which city" or "which day."

    

      
notebook cell

      
hottest_city_idx = temps.mean(axis=1).argmax()
print(cities[hottest_city_idx])

      
Output
Cairo

    


    

      Common Mistake
      
Mixing up which axis means "per row" and which means "per column." If the result is confusing, check the output shape first — it always tells you exactly which dimension survived.

Linear Algebra & Random Sampling


    
Dot products & matrix multiplication

    
A weighted score — say, combining a week's temperatures with a per-day importance weight — is exactly a dot product.

    

      
notebook cell

      
weekday_weight = np.array([1, 1, 1, 1, 1, 0.5, 0.5])
weighted_scores = temps @ weekday_weight   # (5,7) @ (7,) -> (5,)
print(weighted_scores)

      
Output
[122.  184.   23.5 106.  146.5]

    

    
@ is shorthand for np.matmul() — for two 2-D matrices, it does real matrix multiplication, not element-wise multiplication.

The Full Workflow, Start to Finish

    
Same dataset, one continuous pipeline — every step is something you already built in this note, just chained together the way a real analysis actually looks.


    

      
full_workflow.py

      
import numpy as np

# 1. Build the array
cities = ["Tokyo", "Cairo", "Oslo", "Lima", "Nairobi"]
temps = np.array([
    [18, 19, 21, 20, 22, 23, 21],
    [29, 31, 30, 33, 32, 30, 28],
    [4,  3,  5,  2,  6,  4,  3],
    [17, 18, 16, 19, 18, 17, 19],
    [24, 23, 25, 24, 26, 25, 24],
])

# 2. Inspect
print(temps.shape, temps.dtype)

# 3. Convert units
fahrenheit = temps * 9/5 + 32

# 4. Per-city weekly average (axis=1 collapses the days)
city_avg = temps.mean(axis=1)

# 5. Per-day average across all cities (axis=0 collapses the cities)
day_avg = temps.mean(axis=0)

# 6. Flag a heatwave with a boolean mask
heatwave = temps > 28

# 7. Rank cities by average temperature
ranking = np.argsort(city_avg)[::-1]
ranked_cities = [cities[i] for i in ranking]

# 8. Reshape for a downstream model expecting a flat feature vector
features = temps.flatten()
